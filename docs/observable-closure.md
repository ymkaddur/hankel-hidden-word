# Discovery and certification of a finite linear realization

Let a finite alphabet act on a finite-dimensional state by known linear maps. Start with the desired linear observations. Pull back each retained independent query under each symbol, keeping a vector only if elimination shows that it increases the span. Store its source query and word, and record coefficients for every explored transition. At termination the seed span is covered and every generator preserves the retained span. Its minimality follows because each retained vector has a word witness.

There are at most s + a r membership tests, where s is the number of supplied seeds, a the alphabet size and r the final dimension. This counts candidate insertions. Applying the input maps, field arithmetic, elimination, reading the generators and recording coefficients are additional costs. Dense online transitions can cost r² operations per symbol. The map from the initial state to its retained coordinates and all changes to the transition table must also be paid for.

`ObservableClosure.lean` proves the least invariant span, generator-only invariance checking, a certificate for all words and exact equality of the two induced observation functions. Over a finite field of size q with arbitrary initial states, r independent linear readings give qʳ signatures. A deterministic state for all continuations must distinguish them. For a fixed scheduled continuation the required span can be smaller. In particular n independent possible future coordinate readers require n scalar coordinates if the reader is identified after a cut. Announcing its index before the cut reduces the retained state to one scalar and costs up to ceil(log2 n) bits to specify the index. This separation persists with rank-one readers.

`scripts/observable_closure.py` cross-checks the basis algorithm against partition refinement on all labelled states in the stated binary test classes. Related constructions include constrained linear lumping and observable realizations of weighted automata. [Constrained lumping](https://arxiv.org/abs/2004.11961)
